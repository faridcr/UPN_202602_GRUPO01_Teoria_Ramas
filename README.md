## 🌿 Flujo de trabajo

- `master`: rama principal (código estable).
- Cada integrante trabaja en **su propia rama**.
- Cuando el trabajo está listo, se une a `master` con `git merge`.

## 📚 Comandos aprendidos

### Configuración inicial

| Comando | Para qué sirve |
|---------|----------------|
| `git config user.name "tu-usuario"` | Define tu nombre de autor en este repositorio. |
| `git config user.email "tu@correo.com"` | Define tu correo de autor en este repositorio. |

### Básicos

| Comando | Para qué sirve |
|---------|----------------|
| `git init` | Inicializa un repositorio Git en la carpeta del proyecto. |
| `git status` | Muestra el estado de los archivos (nuevos, modificados, preparados). |
| `git add .` | Agrega todos los cambios al área de preparación. |
| `git add archivo` | Agrega solo un archivo al área de preparación. |
| `git commit -m "mensaje"` | Guarda los cambios
